# REG-STATE · 决策与开发状态

> **范围**：登记决定及其来源、当前完成情况、后续开发任务和环境核实结果。
> **不在本文**：行为细则由表中指定的权威文档维护；本文不复制默认参数表。
> **查阅**：先读 §0；决定看 §1，开发接手看 §2 与 §3，环境核实看 §4。

## 0 结论

本文件是开发现状的唯一登记处。“用户确认”说明需求来源，“工程默认”说明可执行的设计选择，“待核实”说明缺少环境证据；三者都不自动代表代码已完成。

### 0.1 接入要点

- **接手开发时**：先看 §2 与 §3，不依据原始说明中的版本号和完成描述跳过实现。
- **改变设计时**：更新 §1 对应决定及其负责正文，随后修改受影响的配置与验收。
- **完成检查时**：只登记实际执行范围；环境未取得时保持未验证，不以文档检查代替运行结果。
